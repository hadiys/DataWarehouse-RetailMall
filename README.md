# Data Warehouse - Retail Mall Analytics
An exercise in data warehousing for retail mall analytics use-case.

## Technologies and Tools:
- Database: Snowflake
- Data modeling: DBT
- ETL: Python, pandas
- Geo Data: Google Earth, geopandas, shapely
- Visualisation: Tableau
